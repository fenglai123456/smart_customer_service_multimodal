# Course Demo Test Data

这个文件夹是课堂汇报用的完整测试数据集合。每个子文件夹对应一个独立测试用例，包含：

- 客服截图：上传到网页里的“客服截图/业务截图”位置。
- 表情图片：上传到“人脸/表情图片”位置。
- 语音文件：上传到“语音文件”位置。
- `case.json`：记录文本输入、语音转写输入、情绪选项、预期识别结果。

使用方式：

1. 打开 `http://127.0.0.1:5000/`。
2. 进入某个子文件夹，例如 `01_fault_repair`。
3. 按该文件夹里的 `case.json` 填写 `text`、`voice_text`、`emotion`。
4. 上传 `screenshot_file`、`emotion_image_file`、`audio_file` 对应的文件。
5. 点击识别，查看最终意图是否等于 `expected_intent`。

注意：这些数据服务于课程演示稳定测试，不作为严格公开数据集达标证据。
